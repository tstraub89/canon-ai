# QA Summary: canon-docs-dedup — Eliminate templates/-root drift via sync script + pre-commit/CI gate

> QA by: Claude | 2026-05-24

## What Changed

canon-ai-dev is dual-use: it runs canon's pipeline on its own repo AND ships its `templates/` tree to adopters via `canon init`/`canon upgrade`. Every canon-managed file exists in two places (root and `templates/`), so every change to a root file needs a matching change in `templates/`. Until now that was a manual discipline — and it wasn't holding. Three paragraphs of `docs/pipeline-orchestrator.md` had drifted from their `templates/` copy across PRs #96/#97/#99, and the `isNoisySourceFile` 3-class exemption added in PR #101 was missing from `templates/scripts/docs-refs-check.mjs`. This task replaces the manual rule with structural enforcement.

**`scripts/sync-canon-templates.mjs`** — New sync script. Copies root canon-managed content into `templates/` in two patterns: wholesale copy for every path in `CANON_OWNED` (plus `.codex/config.toml`), and in-delimiter sync for `AGENTS.md`, `CLAUDE.md`, and `CODEX.md` (only the `<!-- canon:start -->...<!-- canon:end -->` region syncs; outside-delimiter content on each side is preserved independently). Runs as `npm run sync-templates` (apply) or `npm run sync-templates:check` (check-only, exits 1 on any drift, lists drifted paths to stderr).

**`src/lib/canon-owned.ts`** — New shared module exporting `CANON_OWNED` and `DELIMITED` arrays. Both `src/cli/commands/upgrade.ts` and the sync script import from here, so the canonical path list can never drift between `canon upgrade` and the sync script.

**Pre-commit hook via `simple-git-hooks`** — Registered in `package.json` via `postinstall`. Runs `npm run sync-templates` and stages updated `templates/` files on every `git commit`. The pipeline orchestrator's `git commit` call passes no `--no-verify`, so pipeline auto-commits also fire the hook — template updates ride along into the same commit as the root changes automatically.

**CI gate** — `.github/workflows/ci.yml` gains `npm run sync-templates:check` between lint and `docs-refs-check`. Catches drift from contributors who bypass the hook (`--no-verify`) or work without it installed locally.

**Initial sync** — The first `--apply` run resolved all existing drift: `templates/docs/pipeline-orchestrator.md` gained three missing structural paragraphs (auto-commit allow-list, base-drift check, reroute amendment convention). `templates/scripts/docs-refs-check.mjs` got the 3-class noisy-source carve-out. `templates/scripts/docs-refs-check.mjs.d.ts` was created as a new file (wholesale copy). `templates/AGENTS.md`'s in-delimiter region got 2 line fixes (example symbol update + missing validation-matrix row). `templates/CLAUDE.md` and `templates/CODEX.md` were already in sync.

**`CANON_OWNED` extended (AC-14)** — `'scripts/docs-refs-check.mjs.d.ts'` added to the shared module. `canon upgrade` now ships the TypeScript declaration alongside the `.mjs` so adopters who copy canon-ai-dev's test import pattern (`runChecks`, `NOISY_SOURCE_PATHS`) no longer hit type errors.

**Convention doc** — `CLAUDE.md` gained a "Canon-managed file convention" subsection **in the project-additions section** (below `<!-- canon:end -->`), covering: root is authoritative, templates-side edits are silently overwritten on next sync, the pre-commit hook auto-stages, the CI check is the safety net, and new canon-managed files must be added to `CANON_OWNED` or `DELIMITED`. The placement below the delimiter is intentional — these canon-ai-dev-only references must not propagate to adopters via `canon upgrade`. `AGENTS.md` gained a companion workflow note in its own project-additions section.

**Reroute note** — The first implementation placed the AC-12 convention content inside the canon-delimited region of `CLAUDE.md`, which would have shipped internal tooling references (`npm run sync-templates`, `CANON_OWNED`, `simple-git-hooks`) to every adopter. A spec amendment corrected the placement. Running `npm run sync-templates` after the fix automatically removed the content from `templates/CLAUDE.md` — the delimiter sync itself verified the correction.

## How to Test

1. From a fresh clone on the merged branch, run `npm install`. Verify: `cat .git/hooks/pre-commit` shows the sync command.
2. `npm run sync-templates:check` — expect exit 0 and a green "all in sync" message.
3. Edit `docs/pipeline-orchestrator.md` (add a test line). Run `git commit -am "test"`. `git log -1 --name-only` must show both `docs/pipeline-orchestrator.md` and `templates/docs/pipeline-orchestrator.md`. Revert with `git reset HEAD~1 --hard`.
4. Edit inside the canon-delimited region of `AGENTS.md` (between the `<!-- canon:start -->` and `<!-- canon:end -->` markers). Commit. Confirm `templates/AGENTS.md`'s in-delimiter region updated and its outside-delimiter content is unchanged. Revert.
5. Edit `templates/AGENTS.md` below `<!-- canon:end -->`. Commit. Confirm root `AGENTS.md` is NOT modified and the outside-delimiter line in `templates/AGENTS.md` survives. Revert.
6. Add a stray character to `templates/scripts/docs-refs-check.mjs`. `npm run sync-templates:check` — expect exit 1 naming the file. `npm run sync-templates` — stray character removed.
7. On a throwaway branch, commit a drifted state with `--no-verify` and push. CI `sync-templates:check` step must fail and name the drifted file.

## Decisions Made

- **Sync script over symlinks**: symlinks were rejected because canon-on-canon dev work needs outside-delimiter content in `CLAUDE.md` that must not propagate to adopters. The sync script's delimiter awareness handles this cleanly.
- **`src/lib/canon-owned.ts` shared module**: extracting `CANON_OWNED`/`DELIMITED` gives `upgrade.ts` and the sync script one source of truth. Future `CANON_OWNED` additions are reflected in both automatically.
- **`.mjs` entrypoint**: consistent with `docs-refs-check.mjs`, runnable directly via `tsx`, no wrapper needed.
- **`simple-git-hooks`**: minimal single-purpose devDep, config in `package.json`, installs via `postinstall`. Never shipped to adopters.
- **Convention paragraph in project-additions, not canon-delimited**: the amendment proved the enforcement works — running `npm run sync-templates` after the fix automatically removed the text from `templates/CLAUDE.md`.
