The review requests explicit red-first regression evidence for AC-6, which fixes this existing behavior despite the task's feature classification. - [spec] Round-1 revision: AC-6 now requires red-first evidence. Re-probed today's parser to pin the cases: a fenced example table displaces the real one (returns only `example.ts`). A commented table with its own header and separator is returned as live scope, whether it comes before or after the real table. A lone commented row after a live table is NOT returned (lost as a header-less block), so it can't serve as the red-first case. Shape 3 is narrowed per the reviewer note: structural failures drop the whole cell, per-path failures keep siblings.
