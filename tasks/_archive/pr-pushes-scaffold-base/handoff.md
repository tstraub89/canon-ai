## Intent & Rationale

All PR/push callers already funnel through `commitHumanReviewFiles` in `src/orchestrator/main.ts`, including complete-phase retries and full-send. The shared helper consumes the divergence probe's initial list, attempts an all-safe SHA push, and re-lists from that SHA before applying the existing gate. Present-remote runs therefore fetch once before the divergence decision. Missing-remote support is opt-in, leaving ship on its original warn-and-skip path.

The classifier, subject regexes, `hasUnpushedScaffoldCommits`, scaffold-commit writer and existing divergence block text were compared against the base and remain byte-identical. Every non-artifact edit is one of the 17 Affected Files. Managed mirrors were generated from their root copies.

## Edge Cases Considered

- A live origin task branch can cover every base commit: create only the missing branch, without publishing a new commit.
- A stale deleted origin branch must not hide operator commits; failed pruning skips rather than using stale refs.
- Concurrent local base advancement after inspection reaches the post-push gate, while only the checked SHA is published.
- Empty present-remote range returns before classification, push or info output.
- Missing local base fails closed as a list error after missing-remote detection.
- Creation rejection remains fatal despite override; existing-base rejection can fall back to the override.
- Re-list failure after a successful push reports that the base push already happened and stops before the task push.
- Branch names in shell remediation use the existing quoting helper.
