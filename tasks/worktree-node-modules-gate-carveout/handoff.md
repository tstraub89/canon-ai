## Intent & Rationale

The implementation keeps the carve-out narrow and write-inert: only a top-level porcelain entry exactly equal to `node_modules` can be ignored, and only after `lstat` plus realpath-normalized target checks prove it is canon's own worktree symlink to `<REPO_ROOT>/node_modules`.

QA-end only needs the exemption at unexpected-file classification. Human-review filters the entry immediately after porcelain parsing so symlink-only trees flow through the existing clean-tree push/PR retry branch instead of reaching the no-stage `die`.

## Edge Cases Considered

- Wrong-target symlinks are not exempted even when the path name is exactly `node_modules`.
- Real directories are tested without a node_modules ignore rule because `git status -uall` reports their contents, not the bare directory path.
- Probe failures and unresolvable expected/actual realpaths fail closed.
- `buildHumanReviewStagePaths()` remains unchanged and never emits `node_modules`.
